# Smart Folder

Enhanced Unity project folder management plugin, providing better visualization and management experience.

[中文](README.md) | English

## Main Features

- 🎨 Custom folder appearance (icons and colors)
- 📊 Smart stacking indicators
- 🌲 Hierarchy connection lines display
- 📝 Double-line text display
- ⌨️ Convenient keyboard shortcuts

## Installation

### Method 1: Via Unity Package Manager

1. Open Unity Package Manager
2. Click the "+" button in the top left corner
3. Select "Add package from git URL"
4. Enter: `https://github.com/LotusPoi/LotussFolder.git`

### Method 2: Direct Download

1. Download the ZIP file of this repository
2. Extract it to your Unity project's Assets directory

## Quick Start

1. **Customize Folders**

   - Alt + Left Click: Open settings panel
   - Alt + Right Click: Reset settings

2. **Shortcuts**
   - E: Expand/Collapse folder
   - Shift + E: Recursive expand/collapse
   - Ctrl + E: Preset menu
