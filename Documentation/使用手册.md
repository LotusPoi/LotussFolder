## 功能概述

Smart Folder 是一个强大的 Unity 项目文件夹管理插件，它提供了以下核心功能：
- 自定义文件夹外观
- 智能堆叠指示器
- 层级连接线显示
- 双行文本显示
- 快捷操作系统

## 快速开始

1. 安装插件
   - 将插件导入到您的 Unity 项目中
   - 插件会自动集成到 Project 窗口中

2. 基本设置
   - 通过 "Edit > Project Settings > Smart Folder" 打开设置面板
   - 启用您需要的功能模块

## 基本操作

### 文件夹自定义
- **Alt + 左键点击**：打开文件夹设置面板
  - 可以设置自定义图标（支持拖拽外部图片）
  - 可以设置文件夹颜色（支持 RGB/HEX/HSV）
- **Alt + 右键点击**：快速重置文件夹的所有自定义设置

### 快捷键操作
- **E**：展开/折叠选中的文件夹
- **Shift + E**：递归展开/折叠（包含所有子文件夹）
- **Ctrl + E**：打开预设菜单
  - 基础模式：仅显示基本图标和文件名
  - 完整模式：启用所有视觉辅助功能
  - 自定义预设：加载您保存的配置

### 视觉反馈
- 悬停文件夹时会在 0.5 秒后显示完整路径
- 当前悬停的文件夹会显示淡金色轮廓
- 支持深色/浅色主题自适应

## 高级功能

### 动态堆叠指示器
在文件夹右下角显示最多 4 层彩色条，代表文件夹内容：
- 蓝色：脚本文件
- 绿色：预制体
- 黄色：纹理资源
- 红色：动画文件

### 双行文本显示
- 当文件名过长时自动换行
- 严格按空格分割
- 次行文字使用 60% 透明度

### 层级连接线
- 可视化显示文件夹之间的层级关系
- 自动识别末端节点
- 支持深色/浅色主题

### 斑马条纹背景
- 提供清晰的视觉分隔
- 与自定义背景色智能混合
- 自动适应主题颜色

## 性能优化

为确保流畅的使用体验，插件采用了多项优化措施：
1. 使用缓存系统记录文件分析结果
2. 限制每帧最大更新元素数量（≤50个）
3. 智能跳过不必要的重绘
4. 延迟加载和惰性计算

## 常见问题

**Q: 如何备份我的自定义设置？**  
A: 所有设置都保存在 `ProjectSettings/SmartFolder.json` 中，您可以直接复制此文件进行备份。

**Q: 为什么有些文件夹没有显示堆叠指示器？**  
A: 只有包含相应类型文件的文件夹才会显示指示器。空文件夹或只包含其他类型文件的文件夹不会显示。

**Q: 如何临时禁用所有视觉效果？**  
A: 使用 Ctrl+E 打开预设菜单，选择"基础模式"即可。

**Q: 自定义图标支持哪些格式？**  
A: 支持常见的图片格式：PNG、JPG、TGA 等。建议使用透明背景的 PNG 图片以获得最佳效果。
