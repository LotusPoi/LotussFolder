# Smart Folder

Unity 项目文件夹管理增强插件，提供更好的可视化和管理体验。

## 主要功能

- 🎨 自定义文件夹外观（图标和颜色）
- 📊 智能堆叠指示器
- 🌲 层级连接线显示
- 📝 双行文本显示
- ⌨️ 便捷的快捷键操作

## 安装方法

### 方式一：通过 Unity Package Manager

1. 打开 Unity 的 Package Manager
2. 点击左上角的 "+" 按钮
3. 选择 "Add package from git URL"
4. 输入：`https://github.com/LotusPoi/LotussFolder.git`

### 方式二：直接下载

1. 下载此仓库的 ZIP 文件
2. 解压到您的 Unity 项目的 Assets 目录中

## 快速使用

1. **自定义文件夹**

   - Alt + 左键点击：打开设置面板
   - Alt + 右键点击：重置设置

2. **快捷键**
   - E：展开/折叠文件夹
   - Shift + E：递归展开/折叠
   - Ctrl + E：预设菜单
